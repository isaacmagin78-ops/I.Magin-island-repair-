# Watch feed — written by a machine, not a session

`.github/workflows/watch.yml` runs twice a day on GitHub's own
servers and appends anything new below. **It needs no approval, no
API key and nobody to be awake.** Newest entries are at the bottom.

A run that finds nothing still writes a line. Silence and a broken
watcher look identical, and that ambiguity is the whole reason this
file exists.
